# 🧮 Smart Calculator

An advanced calculator web application built using React, JavaScript, Flask, and Python.

The project provides basic arithmetic operations as well as additional mathematical functions through a React frontend connected to a Flask backend.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Percentage
- Square Root
- Logarithm (Base 10)
- Sine
- Cosine
- Tangent
- Error handling
- Responsive React interface

## 🛠️ Technologies Used

### Frontend
- React
- JavaScript
- CSS
- Vite

### Backend
- Python
- Flask
- Flask-CORS
