# TaskFlow - Full-Stack To-Do List Application

TaskFlow is a full-stack To-Do List web application built using React, Flask, and MySQL.

It allows users to create, edit, complete, search, filter, and delete tasks through a simple web interface.

## Features

- Add new tasks
- Add task descriptions
- Set task priority
- Mark tasks as completed or pending
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Pending, and Completed
- Display total, pending, and completed task counts
- REST API using Flask
- MySQL database
- React frontend
- Flask backend
