# CODSOFT Task 3 - Password Generator

## About

This project is a simple Password Generator developed using Python.

It generates strong and random passwords based on the length specified by the user.

## Features

* Allows the user to specify the password length
* Generates random passwords
* Uses uppercase and lowercase letters
* Includes numbers
* Includes special characters
* Validates the minimum password length
* Handles invalid user input

## Technologies Used

* Python
* `string` module
* `secrets` module

## How to Run

1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

```bash
python password_generator.py
```

4. Enter the desired password length when prompted.

## Example

```text
================================
      PASSWORD GENERATOR
================================
Enter password length: 12

Generated Password: A7@kP2!xQ9#m
```

> The generated password will be different each time because the application uses random secure character selection.
